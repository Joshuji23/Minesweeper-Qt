# 扫雷游戏 (Minesweeper)

基于 Qt C++ 开发的经典扫雷游戏，支持左键翻开、右键标记、左右键双击快速展开，内置初级/中级/高级/自定义难度，并记录最佳完成时间。

## 功能特点
- 完整扫雷逻辑，首格不踩雷
- 左键翻开，右键标记/取消旗子/问号
- 左右键同时按快速展开周围格子（经典双击）
- 计时器（mm:ss 格式）
- 最佳时间记录（初级/中级/高级）
- 自定义难度（宽、高、地雷数）

## 技术栈
- C++17
- Qt Widgets (Qt 5.12+)
- 信号槽、状态机、QSettings

## 编译运行
使用 Qt Creator 打开 `.pro` 文件，编译即可运行。
